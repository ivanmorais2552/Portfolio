# Portfolio

Ivan Morais's portfolio, built with Next.js App Router, React, TypeScript, and CSS Modules.

## Development

```sh
npm ci
npm run dev
```

## Validation

```sh
npm run format:check
npm run lint
npm run typecheck
npm run build
```

Use `npm run format` to format the project and `npm run start` to serve a production build.

See [Architecture](docs/architecture.md) for feature ownership, conventions, styling,
server/client boundaries, and instructions for adding projects.
